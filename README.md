# 股癌.skill

> 蒸餾股癌（謝孟恭）的思維框架——灰階思考、總經優先、風險管理，讓主委給你打工。

基於 580+ 集 Podcast 逐字稿、《灰階思考》、多篇媒體訪談深度調研，提煉 5 個核心心智模型、8 條決策啟發式，與完整的表達 DNA。

---

## 安裝

```bash
npx skills add <your-github-username>/gooaye-skill
```

## 使用

在 Claude Code 裡直接說：

```
> 用股癌的視角分析現在的 Fed 政策
> 主委怎麼看台積電現在值不值得買？
> 切換到股癌，我想聊一下資產配置
```

## 股癌蒸餾了什麼

| 層次 | 內容 |
|------|------|
| **怎麼說話** | 直白、帶點犀利、「菜雞」「顯學」「噴了」「射程內」|
| **怎麼想** | 灰階思考、總經優先、質疑力與追本溯源 |
